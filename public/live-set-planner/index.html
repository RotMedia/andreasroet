Gear Libraryi Device: your machines — enter once, reuse forever. Role: what it does tonight. The same box can be drums today and mixer next gig — editable per plan. Power: PSU brick, IEC cable, USB or battery — feeds the pack list. Audio / MIDI cables: counted into the pack list. Watch out: TRS type A and B are not the same! Clock ‹›: master sends the tempo, slaves follow. Exactly one master per set — the app warns if the math is off. Content ‹›: PATTERNS = sequenced on this box, counts into your production budget. PRESETS = sounds you select and play — set list column, no pattern workload. NO = mixer, FX, utility. Checkbox: is this device playing this gig? Unchecked gear stays in your library but out of the plan.

Set List // Pattern Matrixi Rows come from your playlist calculator — one per track, plus your safety net (SN). Track name: working title. Even "the dubby one" beats staring at numbers in a dark club. Cells: pattern or preset slot on that machine — A5, B12, P03. Keep it short, it prints big. ≡ note: details behind the code — track assignments, macro settings, patch notes. Orange ≡ means a note exists. Reorder: drag the ⠿ handle or use the arrows — name, patterns and notes travel together. Re-Order Tracks: makes the current order the new official numbering. Do it once after jamming, before you export.

One row per track, one column per machine. Which pattern lives where — and what's inside it.
